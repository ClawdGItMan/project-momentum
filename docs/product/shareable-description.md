# Shareable Description

## Short Description

Project Momentum is a social self-improvement app that makes progress visible, motivating, and worth sharing. It helps people track the work they are actually doing, stay accountable with others, and build identity around getting better, starting with health and fitness.

## Short Vision

The vision is to make self-improvement feel social, desirable, and culturally cool. Instead of feeds built for distraction or vanity, Project Momentum aims to create a place where consistency, encouragement, and real effort are what earn attention.

## One-Sentence Version

Project Momentum is where progress gets social.

## Slightly Warmer Version

Project Momentum is building a social app for people who want to improve their lives together. The goal is to make showing the work feel better than showing off.
